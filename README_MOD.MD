# 📷 Monochrome Image Messaging Mod

**Ветка:** `feature/monochrome-image-messaging`  
**Версия приложения:** 2.8.0  
**Совместимость:** Android, Desktop (Windows/macOS/Linux), iOS (заглушки)

---

## Обзор

Мод добавляет возможность отправки и получения монохромных (чёрно-белых) изображений через сеть Meshtastic. Изображения кодируются в компактный бинарный формат и передаются как сообщения через порт `PRIVATE_APP` (PortNum 256). Получатель автоматически распознаёт формат и отображает картинку в чате.

## Формат данных

### Заголовок (1 байт)

```
Бит:  [7 6] [5 4 3 2 1 0]
       ENC    PRESET_INDEX
```

- **ENC** (2 бита) — тип кодирования:
  - `00` — Raw (побитовая упаковка)
  - `01` — H-RLE (горизонтальный Run-Length Encoding)
  - `10` — V-RLE (вертикальный, транспозиция + RLE)
  - `11` — Delta + H-RLE (XOR между строками + RLE)
- **PRESET_INDEX** (6 бит) — индекс пресета разрешения (0–9)

### Пресеты разрешений

| Индекс | Размер | Пропорции | Пикселей |
|--------|--------|-----------|----------|
| 0 | 39×40 | ~1:1 | 1560 |
| 1 | 32×32 | 1:1 | 1024 |
| 2 | 48×32 | 3:2 | 1536 |
| 3 | 32×48 | 2:3 | 1536 |
| 4 | 64×24 | 8:3 | 1536 |
| 5 | 24×64 | 3:8 | 1536 |
| 6 | 44×36 | 11:9 | 1584 |
| 7 | 36×44 | 9:11 | 1584 |
| 8 | 52×30 | 16:9 | 1560 |
| 9 | 30×52 | 9:16 | 1560 |

### Стратегии сжатия

При кодировании вычисляются все 4 варианта, отправляется наименьший:

1. **Raw** — побитовая упаковка 8 пикселей в 1 байт
2. **H-RLE** — Run-Length Encoding по горизонтали (хорошо для горизонтальных полос)
3. **V-RLE** — транспозиция матрицы + RLE (хорошо для вертикальных полос)
4. **Delta + H-RLE** — XOR текущей строки с предыдущей + RLE (хорошо для повторяющихся строк)

## Редактор изображений

### Режим рисования (DRAW)

- Пиксельный холст с пропорциональной сеткой
- Кисть (чёрная/белая) и ластик
- Переключатель инверсии (негатив) с динамическим фоном холста
- Кнопки: «Очистить», «Импорт из фото», «Отмена», «Отправить»
- Боковая панель с счётчиком байт и областью для скролла

### Режим импорта фото (PHOTO_CROP)

- `detectTransformGestures` для одновременного масштабирования, перемещения и вращения
- Координатная система в пикселях исходника (скорость перемещения не зависит от зума)
- Fit-inside режим: всё изображение видно при zoom=1, за пределами — нейтральный серый
- Слайдеры: яркость, контрастность, дизеринг (Bayer 4×4)
- Переключатель инверсии
- Кнопки: «Отмена» (назад в DRAW), «Применить» (перенести результат на холст)
- Боковая панель с предпросмотром размера пакета

### UI-элементы

- Выбор разрешения через `FilterChip` (горизонтальная прокрутка)
- Боковая панель (`48.dp`) справа от холста для скролла экрана
- Полноэкранный диалог без рамок

## Антиспам система

- **Кулдаун:** 2 минуты (`120_000 мс`) после каждой отправки изображения
- **Визуализация:** кнопка с круговым прогрессом обратного отсчёта
- **Секретный сброс:** 7 последовательных нажатий на кнопку кулдауна за 2 секунды
- **Реализация:** `imageCooldownTimestamp` в `MessageViewModel`, `ImageCooldownButton` в `Message.kt`
